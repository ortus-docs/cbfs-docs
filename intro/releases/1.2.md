# 1.2

Released September 15, 2026

## Added

* BoxLang certification.
* GitHub Actions updates.
* AI agent integrations.
* Adobe ColdFusion 2025 support.

## Changed

* `createFromFile()` now returns a File object for the created file.
* `upload()` now returns a File object for the uploaded file.
* Dropped support for older CFML engines.
* S3 tests are private because of new AWS S3 security requirements.

## Fixed

* Fixed S3 directory existence checks for explicit folder-marker objects.
* Fixed Adobe ColdFusion S3 binary downloads by removing an unnecessary byte-write operation.
